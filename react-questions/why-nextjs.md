# Q : React 대신 Next.js를 사용하는 이유는 무엇인가요?

<br />

# A : Next.js의 SSR은 요청 시 서버에서 HTML을 생성해 전달하는 방식. 브라우저가 JavaScript를 실행해 콘텐츠를 만들기 전에 내용이 포함된 HTML을 받을 수 있어 **초기 콘텐츠 표시와 검색 엔진 최적화(SEO)에 유리**.

다만 서버 처리 비용과 응답 대기 시간이 발생할 수 있어 항상 더 빠른 것은 아니다. Next.js는 SSR뿐 아니라 정적 생성 등도 지원하며, SSR로 첫 화면을 제공한 뒤 SPA처럼 페이지를 전환할 수도 있다.
