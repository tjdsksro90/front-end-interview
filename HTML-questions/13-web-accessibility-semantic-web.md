# Q : 웹 접근성과 시맨틱 웹에 대해서 설명하고, 시맨틱 태그엔 어떤 것들이 있는지 말해주세요.

<br />

# A : 웹 접근성과 시맨틱 웹은 다음과 같습니다.

- **웹 접근성(Web Accessibility)**은 장애 여부나 사용 환경과 관계없이 누구나 웹사이트를 이용할 수 있도록 만드는 것. 예를 들어 이미지에 대체 텍스트를 제공하고, 키보드만으로도 메뉴를 조작할 수 있게 하며, 글자와 배경의 명암 차이를 충분히 확보하며, 스크린 리더 같은걸 통해서 시각장애인이 음성으로 들을 수 있게 하는 것
- **시맨틱 웹(Semantic Web)**은 웹의 데이터에 의미와 관계를 부여해 컴퓨터도 정보를 이해하고 활용할 수 있도록 하는 개념. 맥락적으로 관련 된 정보 검색하고, 서로 다른 시스템 간의 원활한 정보 교환과 일관성 유지, 기존 데이터 규칙에서 새로운 정보 도출.
예를 들어 `서울`을 단순한 글자가 아니라 `대한민국의 수도인 도시`라는 관계를 가진 데이터로 표현하는 것. HTML로 이해하자면 `시맨틱 HTML`이라고 해서 `article, header, h1, footer`를 사용해서 문서의 의미나 데이터의 관계를 나타낼 수 있음

### 시맨틱 태그의 종류

시맨틱 태그엔 아래와 같은 태그들이 존재합니다.

- `<header>` : 웹 페이지의 헤더를 정의합니다. 보통 로고,제목,네비게이션 링크등이 들어가게 됩니다.
- `<nav>` : 해당 태그 내에서 네비게이션 링크를 정의하게 됩니다.
- `<main>` : 웹 페이지의 주요 콘텐츠를 정의합니다.
- `<article>` : 독립적인 글을 다룰 때 사용되는 태그입니다. 블로그게시물, 뉴스기사, 제품리뷰 등 독립적으로 배포하거나 재사용할 수 있는 독립형 컨텐츠들을 정의합니다.
- `<section>` : 문서의 부분을 의미하는 태그입니다.
