# Q : SPA의 특징과, 이전에 사용하던 방식(MPA) 대비 장점은 무엇인가요?

<br />

# A : 기존의 `MPA(Multi Page Application)`는 페이지를 이동할 때마다 서버에 새로운 HTML을 받아 전체 페이지를 로드합니다. **SPA**는 처음 페이지를 로드한 뒤, Javascript로 필요한 데이터와 화면을 갱신.

페이지 전환이 부드럽고 화면 간 상태를 유지하기 쉽다. 다만 초기 Javascript 로딩이 무거울 수 있고, 클라이언트 렌더링만 사용하면 검색 엔진 최적화와 추가 대응이 필요하다. MPA도 현재 사용되는 방식이며, 서비스 목적에 따라 선택한다.
